# Как участвовать в развитии Reze Zapret

Reze Zapret находится в стадии бета-тестирования, поэтому особенно важны понятные баг-репорты, предложения и отзывы по интерфейсу.

## Ошибки

Используйте шаблон `Ошибка`. Укажите версию Reze Zapret, версию Flowseal, Windows и точные шаги воспроизведения. Скриншоты и обезличенный журнал помогают быстрее найти причину.

## Предложения

Опишите проблему, которую решает идея, и ожидаемый результат. Предложения по интерфейсу можно сопровождать наброском или скриншотом.

## Pull request

Перед крупными изменениями создайте Issue, чтобы согласовать направление. Сохраняйте текущую холодную сине-индиговую палитру, минимальный размер окна 900×680 и совместимость сборки с C# 5 и .NET Framework.

Проверьте изменения командами:

```powershell
.\build.ps1 -OutputPath dist\Reze-Zapret.exe
.\tests\check.ps1
```

Не изменяйте службу Windows и пользовательскую установку автоматически. Такие действия должны выполняться только после явного выбора пользователя.

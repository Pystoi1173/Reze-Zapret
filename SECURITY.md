# Безопасность

Не публикуйте в Issues и Pull Request токены, приватные ключи, персональные данные и полные системные журналы с чувствительной информацией.

Для сообщения о потенциальной уязвимости создайте приватное обращение через Security Advisories репозитория, когда они будут включены, или свяжитесь с владельцем проекта через профиль GitHub.
